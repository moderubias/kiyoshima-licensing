# Rights matrix

This page is an operational summary only. The controlling legal text always
wins over this table and over `KIYOSHIMA.json`.

| Activity | Kiyoshima Open | Kiyoshima Source 1.0 candidate |
|---|---|---|
| Personal use | Standard license controls; no extra Kiyoshima restriction | Allowed |
| Freelance use as a tool | Standard license controls; no extra Kiyoshima restriction | Allowed within Source conditions |
| Education | Standard license controls | Qualifying non-commercial education allowed |
| Research | Standard license controls | Qualifying non-commercial/public-interest research allowed |
| Company evaluation | Standard license controls; no Kiyoshima time limit | 30-day isolated non-production evaluation |
| Company internal production | Standard license controls; no extra Kiyoshima restriction | Separate agreement required |
| Commercial distribution | Standard license controls; notice/attribution conditions may apply | Separate agreement required |
| Hosted/SaaS commercial use | Standard license controls | Separate agreement required |
| Modify/fork | Standard license controls | Allowed only within the Source grants/conditions |
| Redistribute modifications | Standard license controls | Limited non-commercial distribution under Section 6 |
| AI coding/agent use | Within controlling license scope | Within the principal's already-granted rights |
| Model training / fine-tuning | No extra Kiyoshima field-of-use restriction; standard license and applicable law still control | Separate AI permission required |
| Reusable dataset construction | Same as above | Separate AI permission required |

## Interpretation rule

For Open, the Passport intentionally does **not** claim that a standard license
contains AI-specific language. It records only that the Kiyoshima Open profile
adds no extra field-of-use restriction. `klicense preflight` therefore reports
these AI activities as conditional rather than as unconditional authorization.
