- SPDX license inclusion principles: https://github.com/spdx/license-list-XML/blob/main/DOCS/license-inclusion-principles.md
- SPDX request process: https://github.com/spdx/license-list-XML/blob/main/DOCS/request-new-license.md
- REUSE Specification 3.2: https://reuse.software/spec-3.2/
- GitHub repository licensing guidance: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository
- GitHub artifact attestations: https://docs.github.com/en/actions/concepts/security/artifact-attestations
- GitHub artifact attestation workflow guidance: https://docs.github.com/en/actions/how-tos/secure-your-work/use-artifact-attestations/use-artifact-attestations
- WIPO copyright FAQ: https://www.wipo.int/en/web/copyright/faq-copyright
- Open Source Definition: https://opensource.org/osd
- Zenodo GitHub integration: https://help.zenodo.org/docs/github/
- Software Heritage documentation: https://docs.softwareheritage.org/
