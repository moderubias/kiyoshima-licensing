# Licensing profiles

## Open

Use a standard ecosystem license when unrestricted adoption is strategically more valuable than collecting license fees. Default recommendation for foundational libraries: `MIT OR Apache-2.0`.

This profile is intended for crates, SDKs, protocols, interoperability layers, and infrastructure that should become dependencies of other software without organizational legal review.

## Source

Use Kiyoshima Source License 1.0 when source visibility and broad individual freedom are desired while organizations, commercial distribution, hosted commercial exploitation, and model-improvement use remain separately licensed.

## Commercial

Use a negotiated agreement for proprietary products, enterprise deployments, commercial redistribution, SaaS, organizational use, or any scope that needs warranties, support, SLAs, indemnities, negotiated liability, or jurisdiction-specific terms.
