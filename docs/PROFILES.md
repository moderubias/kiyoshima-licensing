# Licensing profiles

## Open

Use a standard ecosystem license when unrestricted adoption is strategically more valuable than collecting license fees. Default recommendation for foundational libraries remains `MIT OR Apache-2.0`.

This profile is intended for crates, SDKs, protocols, interoperability layers, and infrastructure that should become dependencies without organization-specific legal review.

## Source

Use Kiyoshima Source 1.0 when source visibility and broad individual freedom are desired while organization production use, commercial distribution, hosted commercial exploitation, and model-improvement use remain separately licensed.

Organizations receive a bounded non-production evaluation right so they can perform technical/procurement due diligence before negotiating.

## Commercial

Use a negotiated agreement for production deployments, commercial redistribution, proprietary integration, SaaS, support, SLAs, indemnities, negotiated liability, extended evaluation, or jurisdiction-specific terms.
