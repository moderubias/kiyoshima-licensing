# Badges and discovery

For public projects, use the full name in alt text and visible prose even if the badge is compact.

```markdown
[![License: Kiyoshima Source 1.0](https://img.shields.io/badge/license-Kiyoshima%20Source%201.0-informational)](LICENSE)
```

Recommended repository topics:

- `kiyoshima-source`
- `source-available`
- `license-passport`
- `machine-readable-licensing`

The badge is branding/discovery only. `LICENSE` remains authoritative and `KIYOSHIMA.json` remains informational machine metadata.
